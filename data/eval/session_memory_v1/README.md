# 中文会话记忆行为小集

用途：节点8的定点验收，不是训练集，不替代中文多格式知识库评测集，也不宣称代表真实用户分布。

## 题目与来源

- `cases.json`：一条人工构造轨迹中的七个事实问题，覆盖预算更正、日期遗忘、审批码遗忘、项目区分、话题切换、助手猜测与引用伪指令。每题记录预期值和对应用户消息位置；金额不按规律递增。模型只收到问题及输出字段名，不收到标准答案。
- 同文件的R01、R02：引用已有中文知识库评测题与资料定位，不重新编造文档答案。给定一轮明确文档对象的历史，比较省略式追问与原有完整问题。
- `followup_transfer.json`：R03把同一句法定代表人追问的历史对象从宏海科技换为太湖远大，与R01形成对象切换对照。答案、来源沿用既有 `wb-192-02-02` 标注。
- `query_resolution_cases.json`：八个可选历史消歧场景，包含明确对象、对象切换、更正、完整问题、歧义、无历史与引用伪指令；业务答案继续引用现有题目，不把答案注入消歧提示词。结果见 `docs/历史查询消歧插件与对照测试.md`。

## 测法与限制

记忆比较完整历史、近期三轮原文和32K历史＋4K摘要。用明确标为“流程举例”的重复文字撑过真实32K阈值；第一次压缩早期事实，第二次将后续更正与遗忘也推进增量摘要。重复文字不增加新的业务事实，但会影响模型阅读；这不是自然采样的长会话。

问答严格JSON评分，布尔、整数、字符串不混用，要求遗忘的字段必须显式返回null。格式错误和语义错误分开复核。仅窗口在缺乏事实时也可能正确返回null，不能仅凭这种命中就认定它记住了“遗忘指令”。

还需单独复核摘要是否保留被要求遗忘的具体值：问答返回null，不等于摘要删除成功，更不等于物理删除原始存档。跨会话隔离、删除与损坏存档等机制继续由已有单元测试覆盖，本轮未做真实模型的跨会话攻击评测。

知识库对照保留真实候选、标准答案、证据和引用。完整问题是人工明确对象的诊断对照，不是已实现的查询改写插件。主事实与引用支持关系由原文复核，字符串命中仅作辅助；不把文档命中率当成回答准确率。

入口：`scripts/evaluate_memory_behaviors.py` 和 `scripts/evaluate_followup_transfer.py`，默认不调用模型，显式 `--live` 才真实调用。报告在 `storage/evaluations/session_memory_v1/reports/`，不是logs目录。完整结果见 `docs/节点8多轮记忆与指代追问验收.md`。
