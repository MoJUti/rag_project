# 回答模型池设计与使用

## 目标与范围

模型池位于节点7的“证据和提示词已经组装好 → 模型生成回答”之间。只管理最终回答，不改变文档解析、向量化、召回、重排或会话摘要模型。

2026-10-15 经用户确认：千问 `qwen3.8-max` 为主模型，关闭思考；智谱 `glm-5.3-flash` 为备用，使用 `low` 档思考。该智谱型号真实请求明确返回不支持关闭思考，因此未继续沿用原先的关闭参数。后续可扩展其他供应商，但不在本次添加负载均衡、模型竞赛或自动质量路由。

## 调用规则

1. 每个问题优先请求千问。
2. 正文尚未输出时，连接失败、超时、HTTP 429、HTTP 5xx 可以切至已启用的智谱；每个成员最多尝试一次，不循环回切。
3. HTTP 400、401、403、404、响应格式错误等直接明确报错，避免掩盖参数、权限或模型名称问题。
4. 一旦开始输出正文，发生异常就终止本次回答，不拼接另一模型的输出。
5. 正常拒答、资料不足、缺少引用，不触发备用模型。无检索证据时依旧由回答链直接拒答，不请求任何回答模型。
6. 下个问题重新优先千问，不因为前一次故障永久切换。

两次调用可能分别计费；故障请求是否计费以供应商为准。切换并不代表答案质量提升，智谱质量仍需单独评测。

## 配置

本地 `.env`：

```dotenv
CHAT_MODEL=qwen3.8-max
CHAT_FALLBACK_PROVIDER=zhipu
ZHIPU_CHAT_MODEL=glm-5.3-flash
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ZHIPU_API_KEY=
```

千问继续读取 `DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL`。填入智谱密钥后，将 `CHAT_FALLBACK_PROVIDER` 改为 `zhipu`，重启应用。主动启用但配置缺失时明确报错，不静默忽略备用配置。

使用独立的 `ZHIPU_*` 名称，避免用户提供的通用 `AI_MODEL`、`AI_BASE_URL` 覆盖千问或其他模块配置。密钥只保存在已忽略的 `.env`，不能提交到 Git。

## 核心实现

- `generation/model.py`：回答入口工厂，组装默认模型与模型池；旧原生SDK适配器保留兼容，不再用于默认回答入口。
- `generation/model_pool.py`：`CompatibleChatModel` 实现 LangChain 聊天模型接口；`AnswerModelPool` 处理有序备用切换。
- 千问发送 `enable_thinking=false`，智谱发送 `thinking={"type":"enabled"}` 和 `reasoning_effort=low`。两家使用同样的证据、提示词、历史和生成限制，不允许备用模型绕过来源约束。智谱流内的思考正文不展示；接口返回的用量原样保留，不能把 `low` 当成关闭思考或零思考费用。
- 每次调用独立管理连接，直连且不读取环境代理；连接超时10秒，读取超时45秒，响应和连接均在完成或异常后关闭。读取超时不是整次请求总时限。
- 成功模型、请求ID、结束原因和返回的Token用量通过消息元数据及标准回调记录；发生备用切换时记录明确警告，不输出密钥、请求头或响应全文。当前聊天界面尚未新增模型选择按钮。
- 评测缓存身份加入接口地址、备用供应商和备用模型，避免不同模型池的答案混用缓存。

## 验证与限制

新增11项自动测试覆盖：正常回答、正常拒答、输出前切换、输出后禁止切换、鉴权失败、空结果、全部失败、下个问题恢复千问优先、配置校验、两家关闭思考参数、连接关闭、响应异常以及模型/用量回调。完整测试共104项。

2026-10-15 千问通过新的正式模型池入口真实返回“连接成功。”，并记录模型、请求ID、`stop`结束原因及Token：输入19、输出3、共22。另一次初次连通调用输入25、输出3、共28；这些只是连通验证，不是知识库问答质量评测。

智谱密钥已填写；使用 `low` 的真实请求成功返回“连接成功。”，输入19、输出5、合计24 Token，接口报告该简单请求的 reasoning_tokens 为0。这只代表该次请求，不表示模型始终不消耗思考Token。已启用本地智谱备用；同题知识库回答质量尚未验证，不能把连通或接口替身测试视为质量验收。

另模拟千问在首字前连接超时，经模型池切换至真实智谱接口成功，备用调用输入19、输出5、合计24 Token；模型、请求ID、结束原因和用量回调正常。千问故障为测试模拟，不是实际平台宕机。

接口依据：[智谱对话补全文档](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)、[千问模型页](https://www.qianwenai.com/models/qwen3.8-max)。具体型号能否使用，以用户账户权限和真实请求为准。
