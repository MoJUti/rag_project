# 对话刻度导航复现说明

## 1. 原始源码核查结果

本机桌面应用版本为 `26.1007.9446.0`。本轮只读检查了程序安装目录中的 `app/resources/app.asar` 及旁边的 `app.asar.unpacked`，没有读取账号或聊天数据，没有修改桌面应用。

资源包中找到了与截图匹配的编译脚本和样式：

- `thread-user-message-navigation-rail-app-e08aca9a47a3.js`
- `thread-user-message-navigation-rail-ad05f21510d7.js`
- `floating-navigation-rail-layout-db376302e911.js`
- `floating-navigation-rail-layout-17bd6c59412b.css`

相关脚本末尾有相对路径形式的 `sourceMappingURL`，但资源包里没有 `.map` 文件，旁边的解包资源目录也没有相关映射或原始组件文件。相关脚本不含内嵌映射或 `sourcesContent`。因此，本轮取得的是可分析的运行代码，未取得带原始命名、注释和类型的官方原始组件源码；不宣称通过格式化就还原了源码，也不将随应用分发等同于开源授权。

项目实现依据用户截图与核查到的行为参数独立编写，没有将官方打包脚本、样式或其他应用资源复制进项目。

## 2. 本版交互规则

| 项目 | 行为 |
| --- | --- |
| 显示条件 | 当前会话至少有4条用户消息，助手回答不计入数量 |
| 刻度布局 | 一条用户消息一个刻度，每项固定10像素高度，不均分整栏、不添加装饰性假刻度 |
| 高度增长 | 随轮数增长，整体垂直居中；不超过70vh、40rem和聊天区域可用高度中的最小值 |
| 悬停联动 | 当前刻度26像素，距离1、2、3项的刻度依次为20、14、10像素，更远处6像素；约160毫秒平滑过渡 |
| 当前轮次 | 根据正文滚动位置强调对应刻度；当前位置与鼠标悬停目标分开处理 |
| 独立滚动 | 刻度超出上限后只滚动刻度列表，隐藏滚动条，不带动正文；正文位置更新时可将当前刻度带入列表视区 |
| 溢出渐隐 | 顶部还有内容时顶部渐隐，底部还有内容时底部渐隐；渐隐距离上限40像素，不给每根横线做渐变 |
| 预览卡 | 初次悬停约150毫秒后显示问题及本轮回答片段；允许移入卡片操作，长问题及回答截断 |
| 预览安全 | 复用现有Markdown渲染，不支持原始HTML；预览图片只显示说明，链接只显示文字，不加载远程图片或意外离开工作台 |
| 跳转 | 点击刻度仅滚动聊天容器；回看期间新回答不抢回底部 |
| 键盘 | 方向键、Home/End选择刻度，Enter激活，Esc收起预览；减少动态效果设置下取消刻度动画与平滑跳转 |
| 收藏 | 预览卡可收藏/取消收藏，刻度显示小点；本机浏览器按会话ID保存收藏轮次，不保存正文、不修改后端历史 |

收藏保存于 `localStorage` 的 `rag.timeline.bookmarks:<会话ID>`。刷新可恢复，但不跨浏览器或设备同步；存储不可用或损坏时明确报错，导航仍然可用。轮次键假定历史只追加，未来若支持删改/重排历史，需要改为后端提供的稳定轮次ID。

## 3. 实现位置与布局关系

- `frontend/src/ConversationTimeline.tsx`：消息与刻度映射、悬停邻近关系、预览定时器、正文定位、溢出状态和本机收藏。
- `frontend/src/styles.css`：固定间距、居中与高度上限、刻度缩放、预览卡和滚动渐隐遮罩。
- `frontend/src/App.tsx`：提供当前会话ID、正文容器和暂停跟随回调。

刻度导航位于左侧，正文左右宽度拖拽依旧独立保留。为避免两者热区重叠，阅读区至少为主栏两侧合计预留192像素，最大宽度仍不超过1280；狭窄空间允许低于桌面最小宽度，手机布局隐藏刻度及宽度拖拽，不撑开页面。

## 4. 验证与限制

本轮前端24项测试、TypeScript检查和生产构建通过。测试覆盖4轮显示阈值、消息映射、邻近刻度宽度、预览延迟及关闭、容器内跳转、键盘、渐隐两端状态、真实样式约束、收藏保存/恢复/失败、会话切换隔离，以及原有聊天功能。

测试环境不计算真实浏览器几何布局，不能据此宣称视觉逐像素一致。浏览器自动视觉检查受当前工具访问策略限制，需刷新工作台确认鼠标热区、动画观感、卡片位置及长会话滚动。未将应用中的音频可视化等无关实验能力引入知识库系统。
