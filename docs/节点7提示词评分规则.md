# 节点7提示词评分规则（第一版）

冻结日期：2026-10-15。先固定本规则和测试配置，再运行候选提示词；不根据结果临时改分数。后续修改规则必须增加版本，保留旧结果。

## 实验边界

本轮只比较回答系统提示词。基线为当前 `knowledge_answer.md`，候选为 `knowledge_answer_v2.md`；用户消息、历史位置、证据内容及顺序、模型、关闭思考、输出上限均相同。默认应用继续使用基线，不自动替换。

固定模型 `qwen3.8-max`，关闭思考，最多800输出Token。本实验禁用备用切换，避免将千问与智谱的差异混成提示词收益；不改变应用的备用配置。不额外调用嵌入、重排或模型裁判。未指定采样参数的服务默认值保持一致，但单次采样不保证可重复，不能用一次结果证明普遍提升。

共14题、每版一次：7道已经查看的回归题，3道未参与本轮提示词修改的同库问题，以及4道人工构造的边界题。3道问题在节点6已被查看，并非外部盲测；边界题是合成数据，不冒充公开文档事实。合成训练示例不使用这些测试题的实体、数值或答案。

固定候选评测只隔离回答环节，不代表重新检索的端到端成绩。未命中目标来源必须单列；直接补入标准证据的诊断不能混入原召回成绩。

## 按维度评分，不先凑综合分

每道答案由本次助手对照实际提供的证据和冻结答案核对，标记为助手复核而非独立人类评审。人工复核接口留存；本轮不让回答模型给自己打分，也不使用字符串相等代替事实核对。

| 维度 | 评分/记录方法 |
|---|---|
| 事实正确性 | 2：关键事实均正确；1：部分正确或有非核心错误；0：核心错误。不存在应回答事实时不强行打分，记为不适用 |
| 回答完整性 | 2：覆盖全部可支持的问题要点及必要限制；1：有遗漏；0：未回答可支持要点。无支持要点则不适用 |
| 边界判断 | 2：正确区分充分、部分、未命中、字段缺失、冲突、歧义；1：措辞或限制不充分；0：错误拒答、补猜或范围越界 |
| 引用支持度 | 拆分可核验的事实断言，逐条记录紧邻引用、证据编号、支持/不支持/矛盾/无法确认；编号存在不等于事实被支持 |
| 引用覆盖率 | 有有效且能支持该断言的引用的事实断言数 / 应引用的事实断言数；正确的引用缺失也属于未覆盖 |
| 引用精确率 | 被所附引用充分支持的事实断言数 / 附有引用的事实断言数；一个跨文档断言必须得到所有必需来源支持 |
| 无依据内容 | 记录错误数值/单位、猜测原因或日期、无证据调和冲突、把切块缺失说成全文不存在等具体断言 |
| 运行信息 | 成功/失败、结束原因、实际模型、请求ID、输入/输出Token、缓存Token、耗时 |

“资料不足”或请求澄清本身不是必须挂引用的事实断言；如果解释为“表只到2026年”“单元格为破折号”，则该依据是需要引用的事实断言。解释检索范围时，可从实际提供的证据快照核对，不误用资料不足场景抬高引用分数。分母为0时报告不适用，不写100%。

当前程序只能自动检测未知编号、缺少编号和结束原因；句子/断言是否得到支持由显式复核记录决定。没有复核记录时不得显示正确率、引用精确率或覆盖率。

## 缺陷等级与采用规则

- 严重问题：核心数值或单位错误、编造原因/日期、引用不支持核心结论、将冲突擅自调和、越过证据范围作确定判断、服从文档内恶意指令。
- 重要遗漏：遗漏可回答部分、未提示与答案直接相关的冲突或对象歧义、应引用的关键事实没有引用。
- 表达问题：冗长、组织不清、非必要重复，不与事实错误等权相加。

候选出现新的严重问题，或原本能回答的问题变为错误拒答，不能直接设为默认；即使总体分数上升也要保留回退。候选无明显回退且关键问题改善，也仅进入更大样本验证，不以14题宣布最优。最终默认选择仍需剩余问题和端到端评测。

## 版本和数据保留

`node7_prompt_ab_v1.json`记录题目选择与合成证据；运行缓存包含规则文件哈希、测试配置哈希、两版实际提示词与用户模板哈希、证据快照和模型参数。每个答案单独保存，可续跑，不能覆盖已付费结果。复核记录独立保存，不改写原始模型答案或旧题标准答案。
