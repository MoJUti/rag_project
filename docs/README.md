## 当前执行顺序

1. 完成节点 4：保留原有法律条文切块，新增固定 Token 与结构感知策略；在同一评测集上比较证据包含率、边界、重复、超长块和可追溯性，确定数据库实验使用的默认切块方案。
2. 完成节点 5：固定节点 4 的输入和参数，公平比较 Chroma 与 Qdrant，再决定是否迁移。
3. 数据库对比完成后再实现前端切块预览：用户可查看边界、来源、Token 数，并可选择策略、目标 Token、最大 Token、重叠量和表格行数；预览与正式入库必须使用同一套后端配置与版本标识。
