# 节点7提示词首轮对比结果

> 历史记录：本文描述首轮实验当时的文件状态。之后用户要求只保留一份Markdown回答规则，旧候选文件已移除，两版历史正文仍保存在本轮原始JSON中；当前状态见[提示词改写与回归验证](节点7提示词改写与回归验证.md)。

日期：2026-10-15。结论：**候选版尚未证明整体优于基线，暂不替换默认提示词。** 节点7继续进行，不能据此宣布系统验收完成。

## 先约定什么，再做了什么

先保存[评分规则](节点7提示词评分规则.md)和测试配置，再编写候选提示词。候选将原本平铺的规则整理成信息边界、回答前判断、事实约束、引用与输出四部分，并添加3个与测试数据不同的虚构行为示例。

基线 `prompts/generation/knowledge_answer.md` 未修改；候选在 `prompts/generation/knowledge_answer_v2.md`。只有对比脚本显式注入候选，应用默认仍加载基线。

两版都使用 `qwen3.8-max`、关闭思考、最多800输出Token；用户模板和每题上下文完全相同，每题独立历史。实验只保留千问一个成员，不触发智谱备用；应用备用开关未改。对比没有新增嵌入或重排请求，也没有调用模型裁判。

共14题，每版14次：7道已看过的回归题；同库a07、a11、x04三道未参与本轮提示词修改的问题；4道明确标记为人工合成的部分回答、内部冲突、指定来源未提供、文档伪系统指令测试。3道同库题在节点6已用过，并非外部盲测。运行时交替两版先后顺序，但未做严格随机化或重复采样。

## 复核口径和分数

逐题复核由本次助手完成，未调用回答模型给自己打分；但它也**不是独立人类评审**。应允许用户或第二位评审复核，不能把本轮主观边界措辞评分当作客观提升。

| 维度 | 基线 | 候选 |
|---|---:|---:|
| 事实正确性，适用12题，每题0～2 | 24/24 | 24/24 |
| 完整性，适用12题，每题0～2 | 23/24 | 23/24 |
| 边界判断，14题，每题0～2 | 26/28 | 27/28 |
| 本次标注且被引用支持的重要事实断言 | 31/31 | 34/34 |
| 发现严重问题的答案数 | 0 | 0 |

r02未提供目标表、合成scope题未提供指定报告，其目标事实正确性及完整性记不适用，而不是直接记满分；是否恰当说明不足归入边界判断。广告费漏写单位归完整性和边界，不等同于编造了一个错误单位。未知编号或缺资料不会自动触发模型备用。

引用复核按去重后的重要事实断言划分，允许同一局部列表/表格末尾的共同引用支持对应条目，不机械要求每个单元格一个编号；数值计算也核对原始值。重复结论不重复增加分母。推断“速动比率为比值而非金额”依据标准答案和指标含义核对，不宣称它是原文逐字写出的解释。

31和34是本次助手标注粒度下的断言数，非自动、穷尽的句子划分；两版字数与额外事实不同，分母也不同。可据复核文件重算标注口径内的精确率和覆盖率，**不可宣传为知识库引用准确率100%**。未出现错误引用不代表已经覆盖复杂长答案或真实用户文档。

候选每题固定多416输入Token，合计多5,824，约增加12.6%输入。输出没有明显减少。两版缓存命中差异很大，生成长度也不同，单轮耗时差异不应解释成性能提升；表中不是账单，也不是并发基准。总计本轮输入98,100、输出2,683，共100,783 Token，不包含此前连通及7题检查。

## 实现与复现

- `generation/prompts.py`支持显式传入实验系统提示词，同时保留无参数默认行为；版本指纹覆盖实际系统规则和用户模板。
- `scripts/run_node7_prompt_ab.py`固定题目、候选与模型，逐答案缓存，记录两版正文、规则哈希、证据快照、请求ID与Token。
- `scripts/summarize_node7_prompt_ab.py`要求实验完整，逐条核对复核文件和答案哈希，验证复核摘录来自真实回答，再按组别汇总，不自行判断语义。
- `test/test_prompt_ab.py`及`test/test_prompt_ab_review.py`覆盖默认不变、独立历史、固定证据、缓存身份、错误复核、未知引用和空分母。完整自动化测试126项通过；最初一次直接运行测试曾因系统临时目录权限失败，将测试临时目录限定到项目`tmp`后完整通过，未跳过测试。

```powershell
.\.venv\Scripts\python.exe scripts\run_node7_prompt_ab.py
```

已存在的答案会直接复用，不重复付费；失败记录同样保留，不静默换模型或覆盖。不同规则、配置、模板或证据自动产生不同版本的结果文件。

本地文件位于 `storage/evaluations/zh_public_minibench_v0.1/reports/`：

- `node7_prompt_ab_64fee8b1fec7.json`：28份原始回答、完整提示词与固定证据。
- `node7_prompt_ab_64fee8b1fec7_reviews.json`：逐题评分、实际回答哈希、断言摘录与引用支持判断。
- `node7_prompt_ab_64fee8b1fec7_summary.json`：按冻结规则汇总的机器可读数据。

## 后续处理

本轮不切默认、不连续修改到这14题“全过”。优先单独处理仍不稳定的单位限制和片段/全文边界，再用新版本配置及未参与修改的剩余问题验证；本轮14题此后属于已查看回归集。只有固定证据下确有收益，才进入完整检索、重排、证据扩展的端到端对比。记忆与解析提示词仍不在本轮调整范围。
